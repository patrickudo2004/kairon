# Kairon 2.0 Feature Strategy

This document outlines the segmentation between Free and Pro features in Kairon. This serves as a reference for development and future monetization implementation.

## 🟢 Free Tier: Core Production Reliability
*Focused on the mission-critical needs of every event director.*

| Feature | Description |
| :--- | :--- |
| **Offline-First Resilience** | PWA functionality with local backup. The timer never stops, even without Wi-Fi. |
| **Precision Control** | Full access to **Auto-advance** (natural flow) and **Manual** (wait for cue) modes. |
| **The Cue System** | Unified "Hold for Cue" functionality with standby screens for all displays. |
| **Production Views** | Access to TV Mode, Stage Display, and Technician Pro View. |
| **Attendee Access** | Publicly shareable mobile-friendly schedule portal for all events. |
| **Security** | Strict organization-level data isolation and multi-workspace support. |

## 💎 Pro Tier: Professional Excellence
*Focused on high-performance agencies and large-scale conference producers.*

| Feature | Description |
| :--- | :--- |
| **AI Rebalancer** | Smart schedule adjustment via Gemini to recover lost time when running behind. |
| **Brand Identity** | Custom organization logos and accent colors that sync to all TVs and Stage displays. |
| **Event Economics** | Real-time "Event Cost" ticker based on team hourly rates in program settings. |
| **Custom Reach** | Personalized public URL slugs (e.g., `/p/summit-2026`) and iFrame embedding. |
| **Advanced Tools** | Priority support and future team collaboration features. |
